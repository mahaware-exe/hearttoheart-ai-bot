# 💖 Heart-to-Heart AI Bot 🤖🕌

An intelligent, interactive emotional support chatbot built using Python, NLP, and AI — uniquely designed to provide comfort, spiritual support, and learning through an Islamic lens.


## 🌟 Features

- **Emotion Detection**  
  Uses Hugging Face transformers to identify emotions in user input (e.g., sadness, joy, anger).

- **Supportive Islamic Responses**  
  Offers Quranic verses, Hadiths, or motivational quotes based on detected emotions.

- **POS Tagging & NLP**  
  Analyzes language structure using spaCy/NLTK to understand user context better.

- **Interactive Islamic Quiz**  
  Engages users with multiple-choice questions about Islamic history and facts.

- **Emotion Trend Tracking**  
  Tracks emotional patterns over time and visualizes them using pie charts.

- **User-Friendly GUI**  
  Built with Tkinter, providing a smooth interface with buttons, fields, and charts.

---

## 🧠 Technologies Used

- **Programming Language:** Python  
- **GUI Framework:** Tkinter  
- **Emotion Detection Model:** Hugging Face (Roberta-base-go-emotions)  
- **NLP Tools:** spaCy & NLTK  
- **Data Visualization:** Matplotlib  
- **Storage:** JSON for tracking user inputs and scores
